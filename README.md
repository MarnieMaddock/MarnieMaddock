<h1 align="left">Marnie Maddock</h1>

PhD researcher working on neurodegenerative disease using iPSC-derived neuron models and multi-omics approaches.  
Focus on RNA-seq, proteomics, and computational and image analysis to understand selective vulnerability in Friedreich’s ataxia.
